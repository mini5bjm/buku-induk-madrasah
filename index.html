Keamanan Data

Cadangan & Pemulihan Database (Backup & Restore)

Amankan seluruh data buku induk siswa, guru, nilai, dan pengaturan ke dalam file cadangan agar data tidak pernah hilang saat file HTML di-update atau berpindah perangkat.

1. Unduh Cadangan Data

Simpan file cadangan (.json) ke komputer Anda sebelum mengganti file HTML atau berpindah laptop.

2. Pulihkan Data (Restore)

Pilih file cadangan (.json) yang sudah diunduh sebelumnya untuk mengembalikan seluruh data dalam 1 detik.

3. Sinkronkan ke Cloud

Unggah data lokal saat ini ke database online agar langsung muncul saat link Vercel dibuka di browser/laptop lain.
